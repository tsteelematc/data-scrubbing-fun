# Implementation Plan

## Problem
Create a local Python/uv notebook workflow that analyzes `data.csv` and lists languages from highest to lowest by a naive **speakers-per-country** metric:

`naive_speakers_per_country = Number of speakers / country_count`

where `country_count` is derived by splitting the `Countries` column on commas and trimming whitespace, and rows with empty country values are excluded.

## Proposed approach
1. Inspect and normalize relevant fields in `data.csv`:
   - Language name: `Name in English`
   - Countries: `Countries`
   - Speakers: `Number of speakers`
2. Bootstrap a uv-managed project in this folder:
   - Initialize project metadata
   - Create `.venv`
   - Add analysis dependencies (at minimum `pandas` and `jupyter`)
3. Build a notebook that:
   - Loads `data.csv`
   - Parses numeric speakers robustly
   - Computes `country_count` using simple comma split + trim
   - Excludes empty-country rows
   - Computes and sorts naive speakers-per-country descending
   - Displays top results and writes a full ranked table to an output file for reproducibility
4. Add concise run/use instructions so results can be reproduced quickly.

## Todos
- **inspect-data-shape**: Validate dataset columns and practical parsing assumptions (nulls, non-numeric speaker values).
- **bootstrap-uv-project**: Set up uv project scaffolding, virtual environment, and dependencies.
- **implement-analysis-notebook**: Create notebook implementing metric calculation and ranking output.
- **document-run-steps**: Document exact commands to sync environment and run the notebook.

## Notes and considerations
- This metric is intentionally naive and does not weight multilingual overlap, regional distribution, or census quality.
- We will preserve all rows that have parseable speaker counts and non-empty countries under the chosen rule.
- If speaker values include formatting artifacts (e.g., commas), clean them before numeric conversion and keep behavior explicit in notebook cells.
